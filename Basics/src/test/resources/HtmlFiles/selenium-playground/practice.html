01

SearchContext interface

Both WebDriver and WebElement implement SearchContext, which is why you can call findElement on either one. Search from the driver to get the outer card, then search again from that element to reach the nested one — a different context each time.

#scOuter (search from driver)
.scInner (search from #scOuter)
.scLeaf — only reachable by searching inside #scInner
why it matters driver.findElement() and element.findElement() share the same interface, but the second call only searches within that element's subtree — not the whole page.
outer: #scOuter
inner: .scInner (found via #scOuter)
leaf: .scLeaf (found via .scInner)

Shadow DOM

The box below is a real open shadow root, attached with attachShadow(). A plain findElement can't see inside it — you need element.getShadowRoot() (Selenium 4) first.

Handling windows

Opens a genuine new browser tab. In Selenium you'd capture driver.getWindowHandles() before and after, then switchTo().window(newHandle).

This opens this same page in a second tab so you can practice reading getWindowHandles() and switching back.

java String main = driver.getWindowHandle();
for (String h : driver.getWindowHandles())
  if (!h.equals(main)) driver.switchTo().window(h);
